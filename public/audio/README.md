# Audio assets (REF-02)

This folder is the runtime contract between the game and its SFX system.
The game expects three files at runtime, served from `/audio/`:

| File | Purpose |
|---|---|
| `sfx.mp3` | primary audio sprite (mono, 96 kbps recommended) |
| `sfx.webm` | fallback for browsers without MP3 support |
| `sfx.json` | manifest declaring `src` and `sprite` ranges |

When `sfx.json` is **absent**, the engine logs once and runs in no-audio mode.
Nothing breaks: `play()` becomes a no-op, the toggle still persists user
preference, and the game stays fully playable. This is intentional so AI
agents can land code changes without owning binary assets.

## Manifest schema (`sfx.json`)

```json
{
  "src": ["/audio/sfx.webm", "/audio/sfx.mp3"],
  "sprite": {
    "food.eat":         [0,    160],
    "food.timed.expire":[200,  220],
    "damage.hit":       [500,  240],
    "damage.death":     [800,  900],
    "powerup.collect":  [1800, 320],
    "powerup.expire":   [2200, 220],
    "poison.shoot":     [2500, 200],
    "poison.hit":       [2800, 220],
    "boss.spawn":       [3100, 700],
    "boss.hit":         [3900, 260],
    "boss.defeat":      [4200, 1100],
    "phase.intro":      [5400, 900],
    "phase.complete":   [6400, 1400],
    "ui.click":         [7900, 80],
    "ui.toggle":        [8000, 120]
  }
}
```

- Every key must match an `SfxId` (`src/types/sfx.ts`).
- `[start_ms, duration_ms]` per Howler sprite convention.
- Unknown keys are ignored at runtime; missing keys silently no-op.

## Generating the sprite

Use the helper script:

```bash
node scripts/build-audio-sprite.mjs --src ./raw-sfx --out ./public/audio
```

The script accepts a directory of source clips named `<sfxId>.wav` (or `.mp3`)
and produces `sfx.{mp3,webm}` plus `sfx.json`. It validates every file name
against `SFX_IDS` and refuses unknown identifiers. See the script header for
flags.

If you do not have `ffmpeg`/`audiosprite` installed locally, the script falls
back to **manifest-only mode**: it scans your raw clips, validates names, and
emits a `sfx.json` skeleton with placeholder offsets so you can stitch the
sprite manually.

## Source recommendations

- Mono, 22 050 Hz or 44 100 Hz, 16-bit.
- ≤ 200 KB total for the encoded sprite.
- Trim leading silence to keep latency under 50 ms.
- License: pick CC0 or commercial-friendly (e.g. freesound.org with CC0 tag).

## Local override

For local dev you can drop a hand-edited `sfx.json` and a `silence.mp3`
(generated by `ffmpeg -f lavfi -i anullsrc -t 10 silence.mp3`) and rename it
to `sfx.mp3`. Toggle will still play the (silent) sprite slot, validating the
end-to-end pipeline without authoring real sounds.
